### How to read the evidence column

- **Spec**: the feature folder under `specs/`.
- **PR**: the merged pull request on `main`, from `git log --merges`. Feature 019 has no PR of its own: its commits reached `main` in PR #26 (branch `020-fit-tables`).
- **Tests**: backend tests are written as `Class.Method` and live in `tests/server/`. Frontend tests are written as the test file name followed by the test title in quotes, and live in `tests/client/`. Every name was found with `grep` in `tests/`.
- **Manual**: a manual check, with the task and the date recorded in that feature's `tasks.md`.
